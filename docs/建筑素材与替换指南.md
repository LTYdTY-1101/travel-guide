## Studio 中替换

1. 打开主合成或 Scenes 中对应的独立分镜。
2. 选择命名外层，例如 `Landmark · 埃菲尔铁塔`。在右侧 Source 点击铅笔（Change source），选择新图片。
3. 替代素材建议为透明 PNG，全建筑完整入画，底部接近画布下缘；相同画幅比例最容易保持原动画位置。
4. 在 Transform 调整位置、缩放、旋转。停在目标帧，点击对应属性旁的菱形添加关键帧。
5. 在 Controls 的“翻起角度 X（度）”调整立起动画，默认从 -78 度翻到 0 度。该参数已直接暴露在实例源码上，可单独修改关键帧。
6. 建筑、Shadow（落地阴影）、Pin（定位点）、Caption（名称）分别编辑；需要整体移动时多选，或把它们预合成为一组。
7. 旅行卡和终章卡也有独立 Source；更换某个实例不会自动改变别的卡片。要全片统一替换，也可以覆盖同名本地 PNG，然后刷新预览。
