## 参考、音乐与卡点

已复看原录屏 7–24 秒的连续拉远、前进、到站倾斜和建筑翻起；连续帧位于 `previews/flight-reference/`。原片 29.75 秒、44.1 kHz 立体声音轨已提取为 `previews/six-stop-reference/source.wav`。

已使用 UVR-MDX-NET-Inst_HQ_3 对参考音轨 12–23 秒做伴奏分离，再取其中的完整乐句；最终伴奏选段的 VAD 检测语音时长为 0，语音识别未输出口播。分离是实际本地 ONNX 推理，不是静默替换音乐。模型处理与语音复核记录分别见 `separation-audit.json`、`instrumental-speech-audit.json`。

先以频谱正向变化、低频能量、自相关和稳定重音交叉检查：最强约 120 BPM 邻域，不采用旧配乐的固定 120 参数。稳定段 13.725351–21.657324 秒包含约 16 拍，平均约 **121.029 BPM**；实际卡点使用各拍局部检测时点，不用恒定间隔硬套全部音频。

选择避开首尾录屏操作、通知及烟花段的完整 4 小节乐句，按原速延展为 14 个完整乐句；8 ms 边缘处理避免 PCM 点击，不做变速或变调。音频分析、语音检测、伴奏处理记录在 `previews/six-stop-reference/`；最终配乐 `public/audio/reference/europe-reference-score.wav`。不是另一首生成音乐。原 `bgm-120bpm.wav` 不再进入当前主片。

## 空间与融合

继续使用既有 OpenFreeMap / MapLibre 浅色矢量地图、蓝色大圆航迹、飞机与电车，保留来源署名及逐帧瓦片 / React 提交等待。全部镜头可乱序求值，没有 flyTo、播放历史依赖或浏览器计时动画。

市内相机有沿路线前方独立取景点，目的地前 30% 行程开始调整朝向、倾斜、缩放和构图高度；接近景点时观察角降低。展示期间仍有缓慢推进和透视变化；离开时抬升、拉远并把小景观交给电车。机场交接的相机转向分散到整段，避免追随第一条小路快速掉头。车辆与相机朝向分别预计算平滑，逐帧读取同一投影。

六个景观各有原始宽高比、图片内底座中心、贴地阴影宽度、地图观察方向及竖屏构图。修复旧版将高竖图统一装入近方形框而缩小的问题。建筑从底座支点翻起，不从空中落下；集中接触阴影与较柔的远投影分层，光色统一。图片位置和阴影共用同一地图锚点，随缩放适度改变大小。采用真实地图透视和 PNG 景观，不声称可进行真正三维绕楼。

铁塔强调高度，圣母院强调双塔与正面；巴特罗保留高竖立面、米拉使用宽立面；大教堂保留广场纵深；喷泉横向展开并获得最长停留，结束前不缩小退场。

## 编辑与限制

Default Props：`playbackSpeed`、各段 `seconds`、各站 `holdSeconds / revealDelay`、`pitch / heading / heroY / zoom`、`aspect / groundX / groundY / groundWidth`、`size / offsetX / offsetY / subtitle`，以及车辆、路线和音乐音量均可编辑。保存写回内联默认参数；各预览参数分别保存。

地图需要在线瓦片，首次打开和导出仍受公共服务网络速度影响。电车为 OSM 道路走廊上的统一交通示意，不代表运营线路。配乐来自短录屏而非完整原曲母带，乐句延展会有重复，伴奏处理也可能留下轻微分离痕迹；不承诺录屏中所有声部可无损恢复。PNG 景观属于风格化插画，并非测绘三维模型。
