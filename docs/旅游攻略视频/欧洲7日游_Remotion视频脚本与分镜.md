## 连贯动画原则

1. 全片只用一台“虚拟摄影机”：地图缩放、旋转和倾斜连续传递，不在城市间突然跳轴。
2. 每次跨城都沿用同一条红色路线和同一架飞机；城市内部使用较细的红色步行虚线。
3. 景点出现统一采用“地图由正俯视倾斜到 35°–45° → 地点卡翻面 → 建筑展开 → 信息卡落位”的四段式动作。
4. 转场尽量用物体 Match Cut：微信气泡变地图纸张、登机牌变航线、地图边缘变翻页、万神殿圆孔变定位圆点、硬币变路标。
5. 大切换固定在偶数秒整小节；建筑弹起、卡片落下、定位脉冲固定在鼓点或军鼓点。

## 音频设计

- BGM：120 BPM，轻电子 + 弦乐 + 少量世界音乐打击乐；0–8 秒克制，8 秒 Drop，48 秒二次抬升，68 秒 Final Hit。
- 必备 SFX：微信消息提示、纸张展开、定位针落点、卡片滑入、飞机掠过、路线绘制、地图翻页、建筑翻起低频、教堂钟声、脚步、相机快门、水声、硬币、烟花。
- 混音建议：BGM 常态 -14 至 -12 LUFS；旁白出现时音乐自动压低约 5–7dB；转场音效峰值不要盖住旁白辅音。
- 版权：背景音乐与音效使用可商用授权素材，项目中保留来源与许可证记录。

## Remotion 落地建议

- 将 16 个镜头分别封装为独立 `Sequence`，所有时间使用帧数，不用 CSS animation。
- 地图、路线和交通工具保持为常驻底层，城市镜头仅切换相机参数与叠加建筑，保证运动连续。
- 正式地图镜头使用 Google Maps Static API 或合规地图瓦片，不用 AI 生成地图；路线根据真实经纬度绘制为红色，并保留服务条款要求的地图署名。
- 建筑翻起使用 `spring()` 控制 `rotateX`、`translateY`、`scale`，并给底座加 6–10 帧的轻微过冲。
- 音乐按 120 BPM 建立 beat grid：`beat = 15 frames`，`bar = 60 frames`；大场景从整小节开始。
- 在最终选定音乐后，重新检测真实瞬态并微调 ±1–3 帧；视觉卡点优先对齐 Kick、Snare 和明显的 Crash。
- 为避免地图文字抢镜，可对底图做 8–12% 去饱和和轻微高斯模糊，地标模型与路线保持高对比。
