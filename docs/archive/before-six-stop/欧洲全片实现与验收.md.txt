## 地面路线与衔接

17 段：CDG→铁塔、铁塔→卢浮宫、卢浮宫→圣母院、圣母院→圣心堂、圣心堂→CDG；BCN→圣家堂、圣家堂→巴特罗之家、巴特罗之家→米拉之家、米拉之家→BCN；FCO→斗兽场、斗兽场→古罗马广场、古罗马广场→万神殿、万神殿→圣彼得广场、广场→大教堂、大教堂→特莱维喷泉、喷泉→西班牙台阶、台阶→FCO。

几何来自 `routing.openstreetmap.de/routed-foot` 的 OSM 道路 / 步行走廊，原始响应、来源 URL、路由长度和道路吸附点保存在 `public/journey/routes/`，汇总文件是 `public/journey/ground-routes.json`。这是适合地图展示的交通示意，**不代表实际电车轨道、线路、运营方式或导航建议**。画面写“有轨电车 · 前往××”及“市内移动示意”，未编造线路、票价、班次，也未显示距离数字。

路线适度简化并圆滑转角；圆滑后的路线抽样与原始道路走廊偏差限制为 15 米，超出时回退原始几何。原始路线、圆滑几何与速度进度表一并缓存；动画本身无需实时请求道路服务。机场接驳是压缩的地理移动示意，最长道路段为几十公里，不表示实际耗时。

地面已行驶路线为暖橙色实线，前方为浅色虚线。近邻短移，远段拉远再推近，时长不相同。电车朝向依据地理切线，并对整段预计算的连续角度做有限卷积，任意帧直接读取；车辆不会依赖上一播放帧追赶目标。景点先压暗底图，从锚点翻起景观，再落位名称；退场时缩成小景观，留在下一段道路后方逐渐退出。广场→大教堂仅 2.2 秒。

## 地图与可编辑参数

`src/journey/use-tour-map.ts` 复用独立飞行预览验证过的本地 worker、OpenFreeMap 资源协议、重试和 Remotion 加载等待。整段行程使用同一个 MapLibre 实例，按帧 `jumpTo`；相邻镜头相机中心、缩放与方向边界一致。不切换卫星图或国内映射图。使用原有米白陆地、浅蓝水系、低对比道路样式，并保留来源署名。

Composition → Default Props 支持：

- `playbackSpeed`：整体速度，默认 3；改为 1 恢复原速。

- `legs[].seconds`：逐段交通秒数；`legs[].cruiseZoom`：飞行巡航 zoom。
- `stops[].holdSeconds / zoom`：逐景点停留与近景缩放，机场 zoom 同时控制起降近景。
- `planeSize / tramSize / tramArtBearing`：飞机、电车尺寸及素材车头校准。
- `flightColor / groundColor / routeWidth`：路线颜色与像素宽度。
- `cameraPitch / anchorY / showLabels`：地图俯仰、车辆画面高度与地图地名开关。
- `stops[].name / city / day / date`：名称、城市、日期与日程标签。
- `stops[].image / size / revealDelay / offsetX / offsetY`：景观图片、尺寸、登场延迟和相对锚点偏移。
- `musicVolume`：背景音乐；音乐循环至新片尾并淡出，景点音效按新时间线排布。

`calculateMetadata` 随交通 / 停留时长自动更新 Composition 总帧数，日期标签与终章从同一行程表读取。`src/Root.tsx` 中保留内联可写回的默认参数，已检查 Studio 没有“Can't save default props”警告。每个 Composition 的 Default Props 独立保存，修改主片后需要复制相同参数至城市分段并保留各自的 `section`，才能保持同样的自定义数值。原消息卡与机票可继续选中既有命名图层编辑。

建筑展示偏移可直接编辑；如果新增 / 大幅移动地点、改变地面交通起终点，需要更新道路缓存，不能期待修改坐标自动生成新道路。刷新道路依次运行 `node scripts/fetch-europe-ground-routes.mjs`、`node scripts/prepare-europe-route-motion.mjs`，并核对结果；两者以 `public/journey/europe-locations.json` 为基础。
